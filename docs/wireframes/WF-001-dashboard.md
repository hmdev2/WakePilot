# WF-001 — Dashboard

| Região | Conteúdo |
| --- | --- |
| Cabeçalho | Remote Wake Assistant; Configurações; Ajuda |
| Identidade | Computador principal; última verificação |
| Estado principal | PC: Desligado/Pronto/Verificando; bridge: Online/Offline |
| Ação | Botão destacado “Ligar e conectar”; desabilitado com motivo quando necessário |

Estados obrigatórios: verificando, pronto, PC offline/bridge online, ambos offline, configuração incompleta e erro desconhecido. Teclado inicia no título e segue estados antes da ação.
