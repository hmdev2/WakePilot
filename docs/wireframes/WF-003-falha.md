# WF-003 — Falha acionável

| Região | Conteúdo |
| --- | --- |
| Título | Descrição humana, por exemplo “O celular de ativação está offline” |
| Consequência | “Nenhum comando foi enviado ao computador.” |
| Próxima ação | Uma recomendação principal e no máximo duas alternativas |
| Código | ERRxxx e correlation ID, copiáveis |
| Detalhes | Evidências técnicas recolhidas, fechadas por padrão |
| Ações | Tentar novamente; abrir ajuda; voltar |

Nunca mostrar stack trace, chave, MAC completo ou aceitar host alterado.
