# ADR-007 — Separar UI, agente e broker privilegiado

* **Status:** Aceito
* **Data:** 14/07/2026

## Contexto

O projeto exige decisão implementável por equipe pequena, compatível com segurança, Windows/Android e evolução sem reescrever o domínio.

## Decisão

UI roda como usuário; Windows Readiness Agent roda com privilégio mínimo; broker elevado é iniciado somente para operações allowlisted e consentidas.

## Alternativas consideradas

Aplicativo sempre administrador; PowerShell livre; serviço único privilegiado.

## Consequências

Reduz impacto e prompts; aumenta contratos IPC e testes. Broker não recebe comando textual genérico.

## Critério de revisão

Named pipes com ACL, mensagens tipadas, versionadas e limite de tamanho.
