# ADR-002 — Usar .NET 10 LTS com WPF no desktop

* **Status:** Aceito
* **Data:** 14/07/2026

## Contexto

O projeto exige decisão implementável por equipe pequena, compatível com segurança, Windows/Android e evolução sem reescrever o domínio.

## Decisão

.NET 10 LTS e WPF para configurador e launcher; domínio em bibliotecas sem dependência de UI.

## Alternativas consideradas

Alternativas avaliadas: .NET 8+WPF (fim de suporte próximo em nov/2026); WinUI 3 (UI moderna, maior complexidade de empacotamento/ecossistema); Avalonia (multiplataforma desnecessária); Electron (runtime maior e superfície web/Node); Tauri (bundle menor, porém exige Rust e bridge adicional para APIs Windows).

## Consequências

Integração Windows direta, maturidade e viabilidade individual; Windows-only é coerente com MVP. UI deve ser modernizada por design system próprio. Política permite upgrade de runtime.

## Critério de revisão

Se início real ocorrer após outra LTS, atualizar alvo mantendo WPF e testes; não congelar versão fora de suporte.
