# ADR-003 — Usar Termux, Termux:Boot e OpenSSH no bridge do MVP

* **Status:** Aceito com prazo
* **Data:** 14/07/2026

## Contexto

O projeto exige decisão implementável por equipe pequena, compatível com segurança, Windows/Android e evolução sem reescrever o domínio.

## Decisão

Bridge MVP usa pacote bootstrap verificável, boot script e OpenSSH com forced command. App Android nativo é evolução prioritária.

## Alternativas consideradas

App Kotlin nativo com foreground service; daemon dedicado; função nativa da VPN.

## Consequências

Valida rapidamente o caminho crítico, mas instalação é mais frágil, depende de origem compatível e otimizações de bateria. Não é solução definitiva para massa.

## Critério de revisão

Migrar para Kotlin se teste de boot/24 h não atingir RNF005/RNF015 ou antes de distribuição ampla.

## Rastreabilidade

Relaciona-se a 03-escopo-mvp.md, 08-arquitetura.md, 15-seguranca-e-privacidade.md e aos requisitos não funcionais aplicáveis.
