# ADR-005 — Usar SSH com host pinning e forced command

* **Status:** Aceito
* **Data:** 14/07/2026

## Contexto

O projeto exige decisão implementável por equipe pequena, compatível com segurança, Windows/Android e evolução sem reescrever o domínio.

## Decisão

Ed25519 exclusivo por notebook; host key fixada presencialmente; authorized_keys restringe comando, PTY e forwarding; wrapper valida JSON tipado.

## Alternativas consideradas

Tailscale SSH; HTTPS/mTLS; WebSocket; shell SSH comum.

## Consequências

Reutiliza OpenSSH e reduz esforço, mantendo autenticação própria. Configuração incorreta é risco crítico e recebe testes de escape.

## Critério de revisão

App Android nativo deverá migrar para protocolo autenticado próprio/mTLS sem quebrar IBridgeCommandClient.

## Rastreabilidade

Relaciona-se a 03-escopo-mvp.md, 08-arquitetura.md, 15-seguranca-e-privacidade.md e aos requisitos não funcionais aplicáveis.
