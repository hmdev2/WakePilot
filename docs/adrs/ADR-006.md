# ADR-006 — Usar persistência híbrida SQLite + cofre do sistema

* **Status:** Aceito
* **Data:** 14/07/2026

## Contexto

O projeto exige decisão implementável por equipe pequena, compatível com segurança, Windows/Android e evolução sem reescrever o domínio.

## Decisão

SQLite para domínio/histórico; DPAPI/Credential Manager para segredo/referência; JSON somente bootstrap/exportação.

## Alternativas consideradas

Somente JSON; somente SQLite inclusive segredos; registro do Windows.

## Consequências

Transações e consultas consistentes sem colocar privada no banco. Exige migração, backup e ACL.

## Critério de revisão

Abstrair ISecretVault e IRepository; exportação por DTO sanitizado.

## Rastreabilidade

Relaciona-se a 03-escopo-mvp.md, 08-arquitetura.md, 15-seguranca-e-privacidade.md e aos requisitos não funcionais aplicáveis.
