# ADR-008 — Modelar ativação como máquina de estados observável

* **Status:** Aceito
* **Data:** 14/07/2026

## Contexto

O projeto exige decisão implementável por equipe pequena, compatível com segurança, Windows/Android e evolução sem reescrever o domínio.

## Decisão

Estados explícitos para VPN, bridge, pacote, rede do PC, Windows, serviço e cliente; eventos correlacionados.

## Alternativas consideradas

Script linear com sleeps; ping único; abrir app por tempo fixo.

## Consequências

Permite mensagens corretas, cancelamento e testes determinísticos; requer transições e timeouts formalizados.

## Critério de revisão

Persistir apenas fatos/resultados; estado em execução é reconstruível após crash quando possível.

Relaciona-se a 03-escopo-mvp.md, 08-arquitetura.md, 15-seguranca-e-privacidade.md e aos requisitos não funcionais aplicáveis.
